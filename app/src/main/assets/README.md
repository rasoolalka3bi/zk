# ⚠️ مطلوب: أضف ملف الموديل هنا يدويًا

بدون هذه الخطوة، التطبيق هيتبنى وهيشتغل، لكن **التعرّف على الوجوه مش هيشتغل
خالص** (هتظهر رسالة "موديل التعرّف غير موجود" في الشاشتين).

## الخطوات

1. ابحث عن موديل **MobileFaceNet بصيغة TFLite** (خفيف، مصمم للهواتف، ومجاني
   من عدة مصادر مفتوحة المصدر على GitHub - ابحث عن "mobilefacenet tflite"
   أو "facenet tflite android")
2. تأكد إن الموديل بيتوقع صورة دخول **112×112 بكسل** وبيرجّع مصفوفة
   **192 رقم** (لو الموديل اللي لقيته مواصفاته مختلفة، لازم تعدّل الرقمين
   `INPUT_SIZE` و`EMBEDDING_SIZE` في ملف `FaceEmbedder.kt` ليطابقوا بالضبط)
3. سمّي الملف **`mobilefacenet.tflite`** بالظبط
4. حطه في نفس المسار اللي فيه هذا الملف:
   `app/src/main/assets/mobilefacenet.tflite`

## ملاحظة مهمة عن الدقة

الموديل الأساسي هيدّيك نتيجة معقولة، لكن الدقة الحقيقية بتعتمد على:
- **الإضاءة** وقت التسجيل والتعرّف (حاول تكون متشابهة)
- **حد التطابق** (`MATCH_THRESHOLD` في `FaceEmbedder.kt`) - جرّب قيم مختلفة
  حسب النتائج الفعلية عندك (زيادته يقلل الرفض الخطأ، لكن يزيد القبول الخطأ)
- **جودة كاميرا الهاتف** نفسه

## لو التطبيق اشتغل بدون الموديل

هتقدر تتصفح كل الشاشات وتشوف التصميم، لكن زرار "حفظ الموظف" في شاشة
التسجيل هيفضل معطّل، وشاشة التعرّف هتفضل تقول "موديل التعرّف غير موجود".
