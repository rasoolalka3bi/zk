# نظام حضور بالتعرّف على الوجه

## v0.6 - تعميق الأقسام بتفاصيل وظيفية حقيقية من دليل الجهاز الأصلي

بعد مراجعة دليل مستخدم فعلي لجهاز `uFace800` (نص وظيفي فقط، بدون أي نسخ
بصري)، أُثريت 3 أقسام من الستة الموجودة بتفاصيل وظيفية دقيقة تطابق سلوك
الجهاز الحقيقي:

### 1) البحث في السجلات — أصبح بحثًا فعليًا
كان مجرد سرد كامل بلا فلترة. الآن يدعم البحث **بالاسم** و**فترة زمنية محددة
(من - إلى)** معًا، بالضبط مثل قسم "Attendance Search" في الجهاز الأصلي.

### 2) إدارة USB — اختيار محتوى محدد
كان يصدّر/يستورد كل شيء دائمًا. الآن فيه خانتا اختيار منفصلتان (بيانات
الموظفين / بيانات الحضور)، بنفس فلسفة "Download Options" في الجهاز الأصلي -
تقدر تصدّر بيانات الموظفين فقط، أو الحضور فقط، أو الاثنين معًا.

### 3) النظام — حد التطابق أصبح إعدادًا حقيقيًا قابلاً للتعديل
كان رقمًا ثابتًا في الكود (`MATCH_THRESHOLD`). الآن **إعداد محفوظ محليًا
وقابل للتعديل** من شاشة "النظام" مباشرة، يوازي وظيفيًا إعداد "1:N match
threshold" في قسم System بالجهاز الأصلي - تقدر تشدّد أو تخفّف دقة التعرّف
حسب ظروف الإضاءة والاستخدام الفعلية عندك، بدون الحاجة لتعديل الكود.

## ⚠️ تذكير مهم (لا يزال قائمًا)
هذا تعميق **وظيفي فقط** مبني على نص الدليل، وليس أي نسخ بصري. الهوية
البصرية (الألوان، الأيقونات، التخطيط) من تصميمنا نحن بالكامل.

## هيكل الشاشات الكامل (بدون تغيير)
الشاشة الرئيسية، بوابة التحقق الإدارية، والقائمة الرئيسية بستة تصنيفات:
إدارة المستخدمين، الاتصال، النظام (أُثري الآن)، إدارة USB (أُثري الآن)،
البحث في السجلات (أُثري الآن)، معلومات النظام.
